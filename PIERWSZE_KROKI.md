# Pierwsze kroki w Claude Code

1. Rozpakuj ten folder, np. do `~/licytacje-malopolska`, i otwórz w nim terminal.
2. Upewnij się, że masz GitHub CLI i jesteś zalogowany:  `gh auth login`
3. Uruchom Claude Code w tym folderze:  `claude`
4. Wklej polecenie:

   > Przeczytaj CLAUDE.md. Zrób z tego folderu repozytorium git, utwórz publiczne repo GebreI/licytacje-malopolska przez `gh repo create`, wypchnij kod na main i włącz GitHub Pages z gałęzi main (folder /). Podaj mi link do strony.

5. Codzienna aktualizacja – w Claude Code wpisz:

   > Zaktualizuj dane zgodnie z sekcją „Codzienna aktualizacja danych” w CLAUDE.md, potem commit i push.

   Możesz to zlecać ręcznie albo ustawić jako zaplanowane zadanie.
